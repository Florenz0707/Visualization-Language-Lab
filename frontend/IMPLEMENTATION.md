## 🚀 如何使用

### 启动前端
```bash
cd frontend
pnpm install  # 首次运行需要安装依赖
pnpm dev      # 启动开发服务器
```

前端将运行在: http://localhost:9010

### 配置 Mapbox Token
1. 编辑 `frontend/.env` 文件
2. 替换 `VITE_MAPBOX_TOKEN` 为你的真实 token
3. 从 https://account.mapbox.com/ 获取免费 token

### 确保后端运行
```bash
cd backend
uv run uvicorn src.main:app --reload --port 9000
```
